# Minima Release History

## Version 1.0.0 (Initial Release)

### Core Capabilities
- **Typography-First Launcher**: Monochromatic home screen interface designed to eliminate dopamine-driven visual triggers.
- **Cognitive Pause Before Launch**: Configurable timer introducing deliberate friction before opening selected applications.
- **Habitual Loop Detection**: Tracks repeated app opens in short windows to prompt conscious reflection.
- **Foreground Screen Time**: On-device usage aggregation using Android UsageStatsManager.
- **Offline Data Storage**: Local SQLite database via Room and settings via DataStore Preferences.
- **System Event Handling**: Reactive updates upon package installation, replacement, and removal.
- **Privacy Enforcement**: Complete absence of internet permissions ensuring all usage remains on the device.
